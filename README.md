# Gym-Manager
Sistema Web para Gimnasio

Proyecto web desarrollado en **Java** con **Servlets y JSP**, pensado como una simulación de un sistema para un gimnasio.

La aplicación permite gestionar usuarios, roles y un contador de personas dentro del gimnasio, simulando el funcionamiento de un molinete de ingreso/egreso.

Este proyecto fue realizado **de manera conjunta**, como práctica y aprendizaje en equipo.

## Actualmente al app cuenta con:

- Login con manejo de sesión
- Usuarios con roles:
  - **STAFF** → acceso al panel de administración
  - **MIEMBRO** → acceso limitado
- Panel de administración (solo STAFF):
  - Crear usuarios
  - Editar usuarios
  - Eliminar usuarios
  - Ver lista de usuarios
- Contador global de personas dentro del gimnasio

## Tecnologías usadas

- Java 21
- Servlets
- JSP
- JPA / Hibernate
- HTML + CSS
